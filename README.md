# Personal Web Page

Portafolio personal desarrollado con React y Vite para presentar mi perfil profesional, proyectos destacados, experiencia laboral, habilidades y CV descargable.

## Descripción

Este proyecto es una landing page moderna y elegante diseñada para destacar mi perfil como desarrollador y profesional en ciberseguridad. Incluye secciones para:

- Presentación personal
- Hero con avatar y estado de disponibilidad
- Proyectos con imágenes descriptivas
- Experiencia profesional
- Habilidades técnicas
- Enlaces de contacto
- Descarga del CV en inglés y español

## Stack tecnológico

- React
- Vite
- JavaScript
- HTML
- CSS moderno

## Requisitos previos

- Node.js 18 o superior
- npm

## Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/AleeRod/Personal-Web-Page.git
```

2. Entra al directorio del proyecto:

```bash
cd Personal-Web-Page
```

3. Instala las dependencias:

```bash
npm install
```

## Ejecución local

```bash
npm run dev
```

La aplicación quedará disponible normalmente en:

```bash
http://localhost:5173
```

## Compilación para producción

```bash
npm run build
```

Esto genera la versión optimizada para despliegue en la carpeta `dist`.

## Personalización

Puedes actualizar fácilmente:

- textos del perfil en `src/App.jsx`
- estilos visuales en `src/styles.css`
- imágenes en `assets/images/`
- archivos PDF del CV en `public/cv/` y `assets/cv/`
