# Carpeta de archivos del portfolio

## Estructura

- assets/cv/ -> archivos PDF del CV
- assets/images/avatar/ -> imagen del avatar o foto principal
- assets/images/projects/ -> imágenes para cada proyecto

## Cómo usarlo

- Coloca tu CV en español y/o inglés dentro de assets/cv/
- Guarda la foto principal en assets/images/avatar/
- Guarda las imágenes de cada proyecto en assets/images/projects/
- Luego cambia las rutas en el código si quieres usarlas en la web

## Ejemplo de rutas

- /assets/cv/CV_Alejandro_Rodriguez_ES.pdf
- /assets/images/avatar/avatar.jpg
- /assets/images/projects/proyecto-1.png
